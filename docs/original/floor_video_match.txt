# 階のデータと原典の動画の突き合わせ（docs/cmp_video_floors.py が生成）
#
# 10秒おきに切り出した313コマ（Part1 21分＋Part2 30分）を全50階と突き合わせ、
# 階ごとに**いちばん近いコマ**を採ったもの。「ずれ」は121マス中の離れたマス数。
#
# 動画は遊んでいる最中なので、ずれの中身は
#   ・主人公が立っているマス（データに主人公は入っていない）
#   ・そのコマまでに倒された敵／拾われた道具
# で、**0〜5マスなら初期配置とそのまま一致**と見てよい。
#
# 判定の意味:
#   一致/ほぼ一致 … 見分けが付く階で、ずれが12マス以下
#   見分け不能   … 床と星空ばかりで別の階と区別が付かない（ずれが小さくても裏付けにならない）
#   扉が開いたあと … ちがうマスのほとんどが「開いた扉」。遊び進んだ状態のコマしか無い
#   コマ無し     … その階が写ったコマが見つからなかった
#
# 「似た階」は**別の階との最小のちがい**。ここが小さい階は
# （床と星空ばかりで手がかりが少なく）この方法では見分けが付かないので、
# ずれが小さくても**裏付けにはならない**。15マス以上離れている階だけが決め手になる。
#
