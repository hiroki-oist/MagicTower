# 画面の組み立て — 原典 MTE.EXE から読み取ったもの（640x400、1行80バイト）
#
# 出どころ:
#   盤面のマス → 画面位置の式    0x1b6d〜  横 = X*4+0x12（バイト） 縦 = Y*0x20+0x18
#   欄の塗り潰し                 lcall 0xf5f:0x6e9 に渡す VRAM 変位（= 行*80 + バイト列）
#   能力値の描き直し             0xb96c（ここで上限 9990/990/990/9990 もかけている）
#
# 形式: 欄 | x | y | 幅 | 高 | 備考
