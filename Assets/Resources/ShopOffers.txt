# 商店 — 原典 MTE.EXE の商人処理（0x0ea6）と MT.GTX の売り口上を突き合わせたもの
#
# 原典では商人は**階（と、同じ階に2人いる場合はX座標）で品物が固定**されている。
# 売り口上と値段は MT.GTX のレコードに入っていて、買うと商人ごとの「買った」フラグが立ち、
# その次のレコード（提示ID+1）のヒントが聞けるようになる。
#   → 原典ヒント「商人から物を買うと、あとで重要な情報を聞く事をできるじゃろう。」
#
# 形式: 階 | X | 種別 | 内容 | 金額 | 提示ID | ヒントID | 買フラグ | 聞フラグ
#   X       … 同じ階に商人が2人いる場合の区別。1人だけなら "-"
#   種別    … buy=買う / sell=売る / buy_var=値段が変動する / gift=もらう
#   内容    … yellow:n 紫purple:n 赤red:n hp:n matock_super:1 gold:n
#   金額    … buy/buy_var は支払う額、sell/gift は受け取る額。"変動" は下の式
#   ヒントID… 買うと聞けるようになるレコード。無ければ "-"
#   買フラグ… 「もう買った」の番号。原典の表の値 + 0x1e（2階だけは表に無く 0x32 直書き）
#   聞フラグ… 「もうヒントを聞いた」の番号。両方立つと「もう、話す事はないよ。」
#             アイテム所持フラグ(35〜49)・商人(50〜68)・仙人(69〜86)が1つの配列に並んでいる
#
# 値段が変動する鍵屋（12階・X=9）は原典で
#     mov ax, 0x14 ; mul word ptr es:[0x96]
#   すなわち **1本 = 20 × 到達最高階 GOLD**。いくらでも買える。
