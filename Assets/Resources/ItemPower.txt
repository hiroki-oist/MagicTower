# 回復薬・クリスタルの効果量（階によって段階が変わる）
# 出典: 段階値は Java版 MTower.class のセリフ、階との対応は PC98版動画の観測
#
# 観測による裏付け:
#   F2       回復薬 200            → 青薬 段階1
#   F1-10    回復薬 50             → 赤薬 段階1
#   F11-20   回復薬 100 / 400       → 赤薬・青薬 段階2
#   F11-20   パワー/ディフェンスクリスタル +2 → 段階2
#   F31-33   回復薬 200 / 800       → 赤薬・青薬 段階3
#   F31-33   パワークリスタル +4     → 段階3
#   F41-48   回復薬 250            → 赤薬 段階4
#
# ★ F21-30 には回復薬もクリスタルも1つも存在しない（原典データで確認済み）。
#    ストーリー専用のブロックで、アイテム収集が無い。よってこの区間の値は
#    ゲーム進行に影響しない。念のため前後と整合する値を入れてある。
#
# 各区間のアイテム数（原典データより）:
#   F1-10  赤22 青12 攻C7 防C7  = 48個
#   F11-20 赤22 青 6 攻C7 防C7  = 42個
#   F21-30 なし                 =  0個
#   F31-40 赤20 青10 攻C9 防C10 = 49個
#   F41-50 赤16 青10 攻C7 防C7  = 40個
#
# 形式: 最小階-最大階 | 赤い回復薬 | 青い回復薬 | パワークリスタル | ディフェンスクリスタル
1-10  | 50  | 200  | 1 | 1
11-20 | 100 | 400  | 2 | 2
21-30 | 150 | 600  | 3 | 3
31-40 | 200 | 800  | 4 | 4
41-50 | 250 | 1000 | 5 | 5

# 原典の式（MTE.EXE のアイテム取得処理 0x2636〜 より）:
#   block = (現在階 - 1) / 10 + 1
#   赤い薬 = block×50 / 青い薬 = block×200 / クリスタルは攻防とも block
#   上の表はこの式を展開したもの。21-30 を 200/800/4/4 と書いていたのは誤りだった。
