# 場面（演出）の中身 — 原典 PC98版 MTE.EXE の各関数から抽出したもの
#
# PositionEvents.txt の「演出 名前」がここを指す。
# セリフはこの順に出る。原典の関数の場所も控えておく。
#
# 形式: 名前 | 原典の関数 | セリフの並び
#   「題名」は題名画面（TitleScreen）。原典は序章の途中でここに入る。
#     **絵は貼らず真っ黒**に2行だけ（動画 Part1 t≈31）。
#   「序章の絵」は渦巻きの1枚絵（MTOPSTR）。3行が1行ずつ現れる（t≈34〜41）。
#     文字は絵の側にあり、原典はパレットを差し替えて出していく。
#   「塔の絵」は終幕の塔（MTOWER2）。「終わりの言葉」は白地の1枚絵（MTENDMJ）で
#     段落が1つずつ現れる（動画 Part2 t≈1800〜1825）。
#   「斬りかかる」は金騎士が盤面を斬って回る動き（原典 0x325e の向きの表、14振り）。
#   「閃光」は音7と当たりの絵（自分のマス）。原典 0x6d09〜0x6d42 と 0x73b1〜0x73c6。
#   「駆け上がる」は塔を1階ずつ50階まで上がる演出（原典 0x2386〜0x23cd）。
#     最後に50階の (0,-1) に立つ。
#   「最後の画面」は終幕の1枚絵（原典 0xd45c）。「迷宮ＲＰＧ『魔法の塔』」と
#     「Ｈｉｔ　ａｎｙ　ｋｅｙ！」を出してキーを待つ
#   「奪われる」はゼノに全てを奪われる処理（原典 0x06f1b〜0x06f49）。
#     装備剣=0 / 装備盾=0 / 生命力=400 / 攻撃力=10 / 防御力=10 / 現在階=2
#     立ち位置は 0x0701e / 0x07029 が X=2,Y=7 を書く → 盤面の (-3,-2)
#   「地図 (x,y)=種別」はその階の地図の書き換え。原典も場面の関数の中で直に書いている。
#     40階の「金騎士の突撃」も同じ形で、(0,-2) に門を置いて退路を断つ（原典 0x3540）。
#     金騎士(ID133)は原典では地図に置かず、その場で動く絵として戦うが、
#     リメイクでは中央(0,0)に置いて同じ結果にしている（倒すと解錠 0x79 で褒美と上り階段）。
#   「ボスが現れる」は20階の10コマの動き（原典 0x3119〜0x3194）。
#     96x96（3x3マス）の絵を横5x縦2の10コマとして中心(0,0)に貼る（1コマ 25/60秒）。
#     原典は退路の門を置いたあと、地図の三つ組を当てるより**前**に流す。
#     20階の「ボス登場」は、原典 0x3044 が (0,-3) に門(4)を置いて退路を断ち、
#     続けて (X,Y,値) の三つ組の表（docs/make_unlock_sequences.py で抽出）を
#     1マスずつ適用して中央にボス(ID95)を出す。セリフ121はそのあと。
#   3階の「ゼノとの初対面」も地図を書き換える（原典 0x6ae0）。
#     盤面の番地は `階*0x7c + 11*Y + X`（Y は上から、X は左から）で、原典は
#       ゼノ(0x5b=91) を (X4,Y6) に **床6と交互に50回**書いて点滅させて出す
#       → セリフ110（5行・上端50の窓）
#       → 魔導師(0x5d=93) を (X4,Y7)(X4,Y9)(X3,Y8)(X5,Y8) に **各15回**点滅させて出す
#       → セリフ111 → 閃光 → 題名
#     盤面の座標に直すと ゼノ (-1,-1)、魔導師 (-1,-2)(-1,-4)(-2,-3)(+0,-3)。
#     **魔導師4体は主人公の立つ (-1,-3) の上下左右**で、囲まれる形になる。
#     点滅は「点滅<回数>,<待ち>」で書く。回数は床とものを入れ替える回数、
#     待ちは点滅のあとの垂直帰線の回数（原典 lcall 0xf5f,0x3f2 に渡す値）。
#     ⚠ **速さは原典と同じにできない**。原典は待ちを入れずに描けるだけ速く
#       入れ替えるので1回が1コマより短い。こちらは1回＝1コマにしてある。
#     **終わりに 0x6ebd〜0x6f0f が同じ5マスを床(6)に戻す**（奪われる直前）ので、
#     2階の牢から3階へ戻ってもゼノも魔導師も居ない。これが抜けていて
#     「3階に戻るとまだ魔術師がいて先に進めない」と報告された。
#   「地図 …」はその段が来たときに当てる。**次に出すページの直前**に書き込むので、
#     ゼノ → セリフ110 → 魔導師 → セリフ111 のように原典と同じ順で現れる。
#   「牢が開く」は盗賊が脱け出したあとの地図の書き換え（原典 0x070c8〜0x070d7）。
#     2階の (-4,-1) と (-3,-1) が床になり、牢から左の通路へ抜けられるようになる。
#     （そこから左端の列を下れば上り階段 (-5,-5) に着く）
