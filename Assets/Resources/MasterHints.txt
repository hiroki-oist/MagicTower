# X,Y は原典では 0〜10（`cmp X, 0xa`、24階の時空の門が X=5,Y=6＝盤面(0,-1) であることで確認）。
# この表の x は Floor_N.txt と同じ -5〜+5 なので 原典の X = x + 5。
# 判定は「話しかけたプレーヤー自身の X」で、隣のマスに立って話しかける形になっている。
#
# 16階の2人目は INITIAL.DAT の ID10（隠し壁と見た目が同じ「何かが隠れている」マス、全50階で4つだけ）で
# (+5,-5) に居る。その左隣 (+4,-5) は普通の隠し壁(ID9)で、壊してそこに立つと X=9 > 8 になり
# 2人目が選ばれる。見えている方の仙人は (-5,-5)、隣に立つと X=1 なので 1人目のまま。
# セリフ85「やれやれ、見つかってしもうたか」＝隠れている方の仙人。
#
# ごほうび（原典 0x01ce〜0x027f）:
#   3階         勇者のオーブをもらう      （アイテムフラグ 0x23 = 1）
#   16階(X>8)   エリクサーをもらう        （アイテムフラグ 0x27 = 1）
#   2階         攻撃力 += 攻撃力*3/100 ; 防御力 += 防御力*3/100（セリフ93「３パーセントだけ上げてやろう」）
