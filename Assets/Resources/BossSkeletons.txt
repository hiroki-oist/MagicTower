# 10階「骸骨に囲まれる」場面の台本 — 原典 MTE.EXE 0x03e0a から起こしたもの
#
# 1行が1手。Cutscenes.txt の書き方と同じで、Cutscenes が「骸骨に囲まれる」の
# 1行をこの並びに広げる。歩きの数字は原典の向きの表そのままで、
#   1 = X+1（右） / 2 = X-1（左） / 3 = Y+1（画面の下） / 4 = Y-1（上）
# 盤面の y は上が＋なので、3 が y-1、4 が y+1 にあたる。
#
# 出発のマスは [bp-0x5c]（X）と [bp-0x5a]（Y）から4バイトおきに8つ、
# 道順は [bp-0x30] から下へ、区切り(5)で8本に分かれている。
# どちらも docs/make_boss_skeletons.py が原典から取り出している。

# 金騎士(81)が奥へ下がる（0x3f52〜0x3fe5）
地図 (+0,+2)=床
地図 (+0,+5)=Enemy_BossSkeleton
歩き Enemy_BossSkeleton (+0,+2) 4,4,4
地図 (+0,+3)=門
閉まる (+0,+3)

# 退路の門が閉まる（0x4007〜0x4016）
地図 (+0,-1)=門
閉まる (+0,-1)

# 左右の封印扉が開く（0x4030〜0x406b）
地図 (-2,+2)=床
開く (-2,+2)
地図 (+2,+2)=床
開く (+2,+2)

地図 (+4,+2)=床
地図 (+0,+2)=Enemy_SkeletonWorrior
歩き Enemy_SkeletonWorrior (+4,+2) 2,2,2,2

地図 (+1,+1)=Enemy_Skeleton
歩き Enemy_Skeleton (+4,+3) 3,2,2,2,3
