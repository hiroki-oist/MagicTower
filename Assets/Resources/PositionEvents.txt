#
# この関数は物体ディスパッチャ(0x23ee)から毎手よばれ、
# 「現在階とプレーヤーのX,Yが一致し、一度きりフラグがまだ立っていない」ときに発火する。
# 原典の X,Y は 0〜10。この表の x,y は Floor_N.txt と同じで x = X-5、y = 5-Y。

# 形式: 階 | マス | 追加条件 | フラグ | 効果
#   追加条件 … "-" / "マスが床:x,y" / "マスが門:x,y" / "フラグ:N" / "持ち物:プレハブ名"
#              "持ち物:" のものは**その持ち物を使い切る**。原典 13階（0x1fd5〜0x2094）は
#              一度きりの印を持たず、持ち物が無くなることで二度目が起きない仕組み。
#              フラグ欄が "-" なのはそのため。
#   マス     … "x,y"。33階のフラグ113だけは2か所のどちらでも良いので ";" で並べる
#   効果     … ";" 区切り。
#              "地図 階:(x,y)=門|壁|床"  地形の書き換え
#              "セリフ N"                 その場で出る会話
#              "演出 名前"                別仕立ての場面（原典では専用の関数に飛ぶ）
