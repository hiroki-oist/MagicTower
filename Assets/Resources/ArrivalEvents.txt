# 原典の仕組み:
#   下り階段で降りて 現在階 が 28 になったとき、一度きりフラグ108 が立っていなければ
#     フラグ108 = 1
#     29階(+1,+4) に盗賊(ID21) を置く

# セリフ124「ああ、やっと抜け穴が完成した。…また抜け穴作っといたぜ。」と対応する。

# 階段の処理を EXE 全体で調べたが、この種のできごとはこの1件だけだった。
#
# 形式: 着いた階 | 向き | フラグ | 効果
#   向き … 下り / 上り
#   効果 … ";" 区切り。"地図 階:(x,y)=床|物体名" の形
