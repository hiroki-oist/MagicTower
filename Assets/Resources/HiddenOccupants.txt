# 隠れている者の表 — 原典 PC98版 MTE.EXE の関数 0x02c6 から抽出したもの
#
# 地形 ID10 は隠し壁(ID9)と見た目が同じマスで、全50階でこの4マスしか無い。
# そこへ歩こうとすると（＝隠し壁を壊すと）この関数が呼ばれ、そのマスが下の物体に化ける。
# プレーヤーは壊した手前のマスに立ったままなので、そこから話しかける形になる。
#
#   12階 … 手前(+4,+5) に立つと原典の X=9 → 値段が変動する鍵屋
#   16階 … 手前(+4,-5) に立つと原典の X=9 > 8 → エリクサーをくれる仙人（セリフ85）
#   19階 … 十字架（原典ヒント210「十字架は１９階にあるが、あまり気づいてほしくないな」）
#   41階 … 魔術士Ａ。ただし左右対称の反対側(-4,+4)が床（＝倒し済み）でないと現れない
#           原典ヒント216「４１階の右上に私が隠れているが、その前に左上の奴を倒さないとだめだな」
#
# **48階だけは仕組みが違う**。隠し壁ではなく、**床と見分けのつかない地形 ID7** の
# マス（左上隅 (-5,+5)、全50階でここ1マスだけ）で、そこへ歩こうとすると
# 原典 0x02f3c が同じように音6を鳴らして魔導師(ID93)を書き込む。
#   原典ヒント236「４８階の門を守っている敵は、とある場所に姿を隠している」
#   この魔導師を倒すと (-5,+5) が床になり、解錠 0x7f が (+2,-2) の門を開ける。
# 見た目も歩こうとしたときの扱いも同じなので、同じ表に並べてある。
#
# 形式: 階 | マス | 現れるもの | 原典のID | 条件（- / マスが床）
12 | +5,+5 | Merchant    | 19  | -
16 | +5,-5 | Master      | 25  | -
19 | +0,+3 | Cross       | 39  | -
41 | +4,+4 | Enemy_ID151 | 151 | -4,+4
48 | -5,+5 | Enemy_ID93  | 93  | -
