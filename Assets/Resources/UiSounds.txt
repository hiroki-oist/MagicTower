# **原典に無い音**（作者の指定）。触ったときの手ごたえの「ピッ」。
#
# 書式と記号は Resources/Sounds.txt と同じ（原典の音源ドライバの記法）。
# 番号は原典が使う 1〜13 とぶつからないように **90番台**にしてある。
#   i0x3fe … 原典の音11（門が1マス開く「ピッ」）と同じ音色
#   i0x41b … 原典の音6（物を拾う）と同じ音色
#   i0x3e1 … 原典の音9/10（斬る・当たる）と同じ音色
# 音長は原典の刻み（実長はその3倍）。t130 で 1刻み ≒ 0.0096秒なので
#   :2 ≒ 0.06秒 / :3 ≒ 0.09秒。触った手ごたえはこれくらいが気持ちいい。
#
# 候補（どれを使うかは SoundCues.txt の「触る」「決める」の行で決める）:
#   90 ピッ        … 門が開く音と同じ音色。素っ気なくて邪魔をしない
#   91 ピッ（高）  … 同じ音色で1オクターブ上。抜けがよい
#   92 ピピッ      … 短いのを2つ。押した手ごたえが強い
#   93 ポッ        … 拾う音の音色。やわらかい
#   94 ピロッ      … 低→高の2音。決めた感じが出る
#   95 コッ        … 低めの1音。小さく主張しない
