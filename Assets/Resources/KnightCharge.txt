# 金騎士の突撃の道順 — 原典 MTE.EXE 0x325e が持っている向きの表
#
# 1バイト＝1歩。`[bp + si - 0x92]` を si を増やしながら読む。
#   1 = X+1（右） / 2 = X-1（左） / 3 = Y+1（画面の下） / 4 = Y-1（上） / 5 = 区切り
# 原典の Y は下へ増えるので、盤面（y は上が＋）では 3 が y-1、4 が y+1。
#
# 全89歩。区切りで区切ると14まとまりで、
# ジグザグに降りていって、最後にまっすぐ下りてから上へ戻る。
#
# 形式: 1行が1まとまり（区切りまで）。数字は上の向き。
3 1 3   # 下右下
1 3 1 3   # 右下右下
1 1 3 1 3   # 右右下右下
3 2 3   # 下左下
2 3 2 3   # 左下左下
2 2 3 2 3   # 左左下左下
3 1 3 1 3 3   # 下右下右下下
1 3 1 3 1 3 3   # 右下右下右下下
1 1 3 1 3 1 3 3   # 右右下右下右下下
3 2 3 2 3 3   # 下左下左下下
2 3 2 3 2 3 3   # 左下左下左下下
2 2 3 2 3 2 3 3   # 左左下左下左下下
3 3 3 3   # 下下下下
4 4 4 4 4   # 上上上上上
